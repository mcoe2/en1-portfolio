Project 6 + Activity 5 · October 2026

Simple Car + Sensors

For Project 6, the challenge was to build and program a simple car that could drive forward and backward at slow and fast speeds, spin clockwise and counter-clockwise, and drive both a small arc and a big arc.

For the Programming with Sensors activity, I used AI to help write code that reads a sensor input and uses it to control a motor output, as practice for the Astronaut Tools project. I used the color sensor on a small two-wheeled car: when I hold a colored LEGO brick up to the sensor, the car reads the color and drives.
