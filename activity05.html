Activity 5: Programming with Sensors

For Activity 5, I used AI to help write code that reads a sensor input and uses it to control a motor output, as practice for the Astronaut Tools project. I used the color sensor on a small two-wheeled car: when I hold a colored LEGO brick up to the sensor, the car reads the color and drives.
